# Waste Movement Utils HTTP Errors

HTTP errors for the Waste Movement services: HTTP status codes, error types and the RFC 9457 problem-details error handler, which is a Hapi plugin. It has no dependencies.

## Installation

```bash
npm install @defra/waste-movement-utils-http-errors
```

`@defra/waste-movement-utils` re-exports everything in this package, so a service that installs that needs nothing more.

## Development

This package lives in [waste-movement-utils](https://github.com/DEFRA/waste-movement-utils) under `packages/http-errors`. It is tested and released from the root of that repository, and the README there says how.
