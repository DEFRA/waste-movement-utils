# Waste Movement Utils Reference Data

Reference data for the Waste Movement services: EWC, HP, POP, container and disposal or recovery codes, regexes and their lookup helpers, and the value lists the receipt rules share, such as means of transport. It has no dependencies.

## Installation

```bash
npm install @defra/waste-movement-utils-reference-data
```

`@defra/waste-movement-utils` re-exports everything in this package, so a service that installs that needs nothing more.

## Development

This package lives in [waste-movement-utils](https://github.com/DEFRA/waste-movement-utils) under `packages/reference-data`. It is tested and released from the root of that repository, and the README there says how.
